# ESP32 Web Термометр (DS18B20)

Простий веб-термометр на ESP32 з датчиком DS18B20. Температура відображається у браузері та автоматично оновлюється кожні 2 секунди.

## Що потрібно

- Плата ESP32
- Датчик DS18B20
- Резистор 4.7 кОм (підтягуючий, між DATA і VCC)
- Arduino IDE з підтримкою ESP32

## Бібліотеки

Встановіть через Library Manager в Arduino IDE:
- `OneWire` (Paul Stoffregen)
- `DallasTemperature` (Miles Burton)

## Підключення

| DS18B20 | ESP32     |
|---------|-----------|
| VDD     | 3.3V      |
| GND     | GND       |
| DATA    | GPIO 4    |

Резистор 4.7 кОм — між DATA і 3.3V.

## Запуск

1. Завантажте скетч на ESP32.
2. Відкрийте Serial Monitor (115200 бод) — там з'явиться IP-адреса плати.
3. Відкрийте цю IP-адресу в браузері — побачите поточну температуру.
